Test me in two minutes

Download the arm64 archive with the button above, or build the same local app from source.

  1. Unzip fluid-coding-v0.1.0-alpha.1-macos-arm64.zip and move fluid-coding.app to /Applications.
  2. Open it. The app serves on 127.0.0.1 and opens your browser. It binds loopback only.
  3. Clear the download quarantine. The ad-hoc signed prerelease is not notarized, so run xattr -cr /Applications/fluid-coding.app, then open it. A first launch may still need right-click → Open.

From a source checkout on macOS:

bash scripts/install-local.sh

INSTALL_DIR=/somewhere changes the destination. From source you can also run pnpm dev plus cargo run -p fluid-server.

Under the hood

Designed for review, measured against FAF budgets

Cached matrix p95 under 20 ms, impact under 100 ms at 100k LOC, an initial JavaScript budget of 150 KB gzip and no graph computation in React. Rust owns the hot path; the WASM facade runs in a worker for browser-only analysis.
