Performance budgets

Fast and responsive is a product requirement. These budgets are release gates. Measure before optimizing; record the result in the PR.

Budgets

Path Budget How
Cached matrix API p95 < 20 ms cargo bench -p fluid-core + local smoke
Impact, 100k LOC graph p95 < 100 ms criterion fixture
Incremental re-index, one file < 2 s integration test with a temp repo
Cold server start, small repo < 150 ms hyperfine ./target/release/fluid-server --check
First contentful paint, local < 300 ms Playwright trace, throttled CPU 4×
Initial JS, gzip < 150 KB scripts/check-bundle.mjs
Map at 5,000 cells 60 fps pan/zoom Playwright + requestAnimationFrame trace
Session graph build, 10k spans p95 < 20 ms criterion bench for build_session_graph
Analysis canvas, 300 visible nodes 60 fps pan/zoom Playwright + requestAnimationFrame trace
Memory, 1M LOC < 300 MB RSS after index and 100 requests
Idle CPU ~0% no polling; SSE only while a job runs

The @xyflow/react v13 chunk for the lazy /analysis route is excluded from the 150 KB initial JS budget; its gzip size is still recorded in the PR when the chunk lands.

WASM adds: one transfer of the graph per generation, no per-cell crossing, worker-owned instance, and a hard cap of 50 ms main-thread work per interaction.

Rules

  1. No N+1 requests. Batch by generation or selection.
  2. No graph computation in React. The server or wasm worker computes; the client renders.
  3. Virtualize lists over 100 rows and draw only visible map cells.
  4. Stream long jobs with SSE; return a job id immediately.
  5. Cache by (generation, query); bump generation on any index mutation.
  6. Avoid JSON round-trips in hot loops; use typed structs and borrowed slices in Rust.
  7. No new UI dependency without a bundle-size note in the PR.
  8. A regression over budget blocks the release unless an ADR records the exception.

Current baseline

Not measured yet. The scaffold has no benchmark harness. First task: add criterion benches for build_matrix and analyze_impact, and the bundle check after the first web build.

The canvas gate is not measured yet; it stays a target until the Playwright rAF trace runs during dogfood. A first criterion run of build_session_graph on 10k spans came in around 5.4 ms with maxNodes: 1000 and reduced sample settings; that is an early signal, not the p95 gate above.
