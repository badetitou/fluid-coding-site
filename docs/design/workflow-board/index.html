Workflow on the Board — dock, task states, worktree selector

Status: draft. Source of the flow: docs/workflow.md (target loop and Decisions). Only section 1 is implemented; sections 2 and 3 are next steps.

1. Fluid Agent dock on narrow widths (implemented)

Problem: at 800 px and below the dock stacked under the page at 72 vh and the Board shrank to a sliver.

Rules (breakpoint 900 px, decided by the user; pure rules in layout/dockSheet.ts):

  • At 900 px and below the dock starts closed. The topbar toggle opens it; taskWorkStarted still opens it.
  • Open, it is a bottom sheet with two heights: peek (44 vh, default) and full (82 vh). The page keeps at least 96 px above the sheet, so the Board header stays visible even in full.
  • A chevron button in the dock header toggles peek/full (aria-pressed, label “Expand the agent” / “Show the page behind the agent”). Hidden above 900 px. The close button is unchanged.
  • Wide screens (above 900 px) are unchanged: side dock, resizable (320-720 px).
  • Motion: height transition 200 ms; prefers-reduced-motion already collapses transitions globally.
  • Keyboard: toggle and close are plain buttons in tab order; Escape-to-close is a next step.
  • 375 px: the dock tabs and composer fit the sheet width; the chat area scrolls inside the sheet.
  • Limits: the 800 px layout is a sheet with the page above it. The shell’s nav stacking stays at 720 px, which is a separate media query.

2. Board states per workflow step (next step)

Columns stay Todo, In Progress, In Review, Done. Each card shows a state strip:

Step Card Details
Intake Draft card (dashed border) in the chat, not on the Board Create / Discard; sub-tasks listed
Todo Plain card Actions: Start work, Autowork toggle (#9)
In Progress Pulsing teal dot, “Agent running”, elapsed time, worktree branch name Action: Open in dock; cancel
In Review Amber badge “Review”, changed-files count Actions: Inspect worktree (#10, done), Comment (#11), Validate (#12)
Done Muted card, merge commit short hash or PR link

All states: empty column (“Nothing here yet” with the next action), loading (3 skeleton cards per column, no layout shift), error (inline banner with Retry; agent errors such as a missing provider or a timeout appear in the chat as an error turn with the cause and a Retry/Configure action, #13 #14), long title (two-line clamp, full title in title and the detail panel), 375 px (columns scroll horizontally with snap; the active column header is sticky), reduced motion (cards move between columns with an instant swap and a short highlight instead of a slide), keyboard (cards are focusable, Enter opens, m opens a “Move to” menu; no drag-only action). Motion otherwise: a card moving column animates transform/opacity only (FLIP), 200 ms.

3. Topbar worktree selector (next step, issue #10)

  • Placement: topbar, left of the dock toggle, after the project name. Same pages serve every scope.
  • Button shows branch glyph and name: main (main checkout) or task/<id> plus a “review” badge.
  • Menu: “Main checkout”, then task worktrees grouped (running, in review), each with status dot.
  • States: main checkout (neutral), task worktree (teal accent bar under the topbar so the scope is never ambiguous), loading (disabled with spinner), error (menu shows retry), empty (only main, menu shows “No task worktrees yet”), long branch name (middle truncation, full name in tooltip).
  • 375 px: shows only the glyph and a 12-character truncated name; the menu opens as a bottom sheet.
  • Keyboard: button is a menu button (Enter/Space/Arrow down opens, arrows move, Escape closes and returns focus). Reduced motion: no slide, fade only.
  • Implemented by ADR-0043 and issue #10: the menu groups main, task worktrees, other worktrees and branches; the In Review card’s “Review changes” and “Analyse run” actions pick the task worktree and open Changes or the scoped session analysis. Status dots, the 375 px bottom sheet and full arrow-key navigation remain refinements.

Open points

  • Escape closes the sheet; focus return to the topbar toggle.
  • Whether Start work on a narrow screen should open the sheet in peek (current) or only show a toast.
