Chat sessions

Durable IDE chat history is stored per project in .fluid-coding/sessions/<id>.json. The Rust ChatSession struct owns the wire shape; chatSessionSchema validates HTTP responses. The shared example is fixtures/contracts/chat-sessions.json.

Invariants

  • Session ids contain only ASCII letters, numbers, -, and _, and are at most 80 characters.
  • One file contains one conversation; each successful agent run appends one immutable turn.
  • Writes use a temporary sibling file followed by an atomic rename.
  • A turn records the user prompt, agent session id, factual messages, patch proposals, optional narrative, and creation time.
  • Project activation switches the store root. Histories never leak across configured projects.
  • Rename changes only the display title. Delete removes exactly one validated session file.
