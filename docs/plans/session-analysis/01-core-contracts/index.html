Brief 01 — Pure core + wire contracts

Goal: define the frozen trace/graph contract in Rust, implement the pure trace → graph transform, mirror it in zod, and add a shared fixture. No I/O, no clock, no async in fluid-core.

Read first

docs/plans/session-analysis/00-shared-contract.md (frozen fields), AGENTS.md, docs/contracts/wire.md, crates/fluid-core/src/lib.rs, crates/fluid-core/src/sessions.rs, packages/contracts/src/agents.ts, packages/contracts/src/index.ts, packages/contracts/src/fixtures.test.ts.

Work

  1. Add crates/fluid-core/src/session_graph.rs with every struct listed in the shared contract, #[serde(rename_all = "camelCase")], Default for GraphOptions, and build_session_graph(&SessionTrace, &GraphOptions) -> SessionGraph. If the file would exceed 300 lines, split into session_graph/model.rs + session_graph/layout.rs + mod.rs.
  2. Layout algorithm (pure, deterministic):
    • one lane per TraceSession, ordered by input order; depth by topological order of parent_span_id, then by start_ms/span_id for stable ties;
    • invoke_agent/session root → session node, chat/inference → turn, execute_tool → aggregated toolBatch edge+node, nested subagent trace → subagent group node with children;
    • consecutive tool spans between two turns collapse into one GraphEdge with call_count, total_duration_ms, avg_duration_ms, error_count and intensity = f(call_count) clamped to 0..1; tool_names keeps at most 8 distinct names;
    • GraphOptions.expanded contains span ids whose batch is expanded into individual tool nodes, still respecting max_nodes and max_calls_per_batch. Overflow is reported in stats.dropped_nodes, never silently dropped without a count.
    • missing parent ids and cycles must degrade gracefully (attach to lane root), never panic.
  3. Unit tests in the same module: aggregation of 3 tool calls into one edge, expansion of a batch, nested subagent group, deterministic order with equal timestamps, cycle/missing-parent safety, max_nodes budget, and a fixture round-trip via include_str!.
  4. Add a small criterion bench for build_session_graph on a 10k-span trace (criterion dev-dep in fluid-core/Cargo.toml, update Cargo.lock). Keep it under benches/.
  5. Mirror every struct in packages/contracts/src/session-graph.ts with the zod schemas and type aliases named in the shared contract. Export from packages/contracts/src/index.ts. zod stays at untrusted boundaries; do not add runtime validation of server JSON in the core.
  6. Add fixtures/contracts/session-graph.json and parse it in both fluid-core tests and packages/contracts/src/fixtures.test.ts. Write docs/contracts/session-graph.md with the JSON example and invariants (aggregation, intensity, caps, deterministic order).

DoD

  • cargo test -p fluid-core passes.
  • cargo check -p fluid-core --target wasm32-unknown-unknown passes.
  • pnpm --filter @fluid-coding/contracts test passes.
  • No file outside your ownership matrix was edited. Report any contract problem instead of changing it.
