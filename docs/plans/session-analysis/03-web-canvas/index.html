Brief 03 — Lazy analysis page and React Flow canvas

Goal: render the frozen SessionGraph in an interactive, lazy-loaded page and open it from Agents.

Read first

docs/plans/session-analysis/00-shared-contract.md, AGENTS.md, docs/quality/performance.md, apps/web/src/App.tsx, apps/web/src/pages/AgentsPage.tsx, apps/web/src/components/SessionList.tsx, apps/web/src/components/agent/ChatHistory.tsx, apps/web/src/components/editor/MonacoEditorBoundary.tsx (lazy pattern), apps/web/src/api/coding.ts, apps/web/src/styles.css.

Work

  1. Add @xyflow/react@^13.0.3 to apps/web/package.json via pnpm add so pnpm-lock.yaml stays consistent. Import @xyflow/react/style.css inside the lazy analysis module only; v13 puts styles in the xyflow CSS layer, so declare the layer order in the page stylesheet if needed. Keep the default React Flow attribution (no Pro).
  2. Make SessionAnalysisPage the app’s first React.lazy route in App.tsx: /analysis?ids=<id1,id2> under Shell, wrapped in Suspense. It must NOT be an eager import: pnpm check:bundle already reports 150.0 KiB initial JS, exactly at budget.
  3. Page (≤150 lines) reads ids/expand from useSearchParams, calls fetchSessionAnalysis(ids, expand), shows loading/error/empty states, and renders a canvas plus a TraceInspector aside. Selection and focused node live in the URL.
  4. apps/web/src/components/session-analysis/:
    • TraceCanvas.tsx — <ReactFlow> with Background, Controls, interactive MiniMap, fitView, onlyRenderVisibleElements, stable nodeTypes/edgeTypes declared outside render, memoized custom components, useCallback handlers, narrow v13 hooks (useNodesData etc.). Pan, zoom, node drag and minimap must work; drag positions stay in local state.
    • TraceNode.tsx — variants for session, turn, toolBatch, tool, subagent, exception, message. Shows label, duration, token badge, expand affordance and a clipped chat excerpt.
    • ToolBatchEdge.tsx — custom SVG edge using getSmoothStepPath/BaseEdge: stroke width and colour intensity both encode callCount; label shows count/avg duration; click expands.
    • SubagentGroup.tsx — React Flow parent group using parentId, with a breadcrumb back to the parent session.
    • TraceInspector.tsx — full message/tool detail for the selected node, with a clear “content not captured” state when contentRef is absent. Keep each component ≤150 lines and ≤7 props; split further if needed.
  5. apps/web/src/lib/sessionAnalysis.ts + .test.ts: pure presentation mapping SessionGraph → { nodes, edges } for React Flow, colour-scale helper and URL parsing. No domain graph computation here (the server owns it); tests cover intensity mapping, selection parsing and hidden children toggling.
  6. fetchSessionAnalysis(ids, expand) in api/coding.ts, validated with sessionGraphSchema from @fluid-coding/contracts (owned by track 01; write against the frozen export names).
  7. Agents entry points: in AgentsPage.tsx add selection state; in SessionList.tsx add a checkbox and an “Analyser” link; add “Analyser la sélection” navigation to /analysis?ids=.... Same action in ChatHistory.tsx for the active dock conversation. Do not add a primary nav item (NavRail.test.ts asserts that list).
  8. Add page styles to apps/web/src/styles.css using existing tokens; no hardcoded colours in components, no antd.

DoD

  • pnpm --filter @fluid-coding/web typecheck passes once track 01 has landed; if contract exports are missing, report it instead of duplicating schemas.
  • pnpm check:bundle still passes and the React Flow chunk is listed as non-initial.
  • pnpm --filter @fluid-coding/web test passes.
  • No file outside your ownership matrix edited.
