ADR-0007 — Change Briefs and explicit trust modes

  • Status: accepted
  • Date: 2026-11-24

Context

Agent edits are hard to review because a diff shows text, not architecture. Users need to see what a change touches structurally, which tags and rules it affects, and what checks say. They also need a predictable safety model for agent writes.

Decision

Every agent turn produces a Change Brief: files and hunks, changed/added/removed symbols, changed and impacted cells by distance, relation changes, tags touched/proposed/orphaned, checks, transparent risk factors, and optional intent/narrative. Facts are generated deterministically; the LLM narrative is optional and clearly separated.

Trust modes: review (read-only), propose (isolated worktree, patch proposal), edit (direct edit with checkpoints and undo), auto (edit + run checks). Default is propose for risky tasks.

Consequences

  • Review is possible without trusting a model’s summary.
  • Every write path must create a checkpoint and an audit entry.
  • UI actions map to a mode; the mode is never implicit.
