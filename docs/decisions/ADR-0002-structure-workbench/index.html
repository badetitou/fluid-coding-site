ADR-0002 — Structure map is home; Miller columns inspect

  • Status: accepted
  • Date: 2026-11-24

Context

A code assistant can open on a chat box, a file tree or an architecture map. Agent-driven work makes the third more valuable: the user needs to understand the system and the blast radius of a change before reading individual files.

Decision

The home is the Structure workbench: a layer × domain map with change and impact overlays. Code is inspected through Miller columns (package → class → method → code), not through a file tree first. Changes are reviewed as Change Briefs. The agent is a persistent dock, not the home page.

Consequences

  • The map must stay fast at thousands of cells; see the performance budgets.
  • A table fallback and keyboard navigation are required for accessibility.
  • Individual file browsing remains possible, but is not the primary navigation model.
