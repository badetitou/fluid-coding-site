ADR-0003 — Merge Model, Structure and git into one code graph

  • Status: accepted
  • Date: 2026-11-24

Context

badetitou/model gives fine-grained, SCIP-keyed entities and relations. badetitou/structure gives a layer × domain quotient, cell symbols, diff impact and history. Git gives the working tree and commits. None is sufficient alone: Model lacks the quotient, Structure is class-level, git lacks semantics.

Decision

Define one normalized CodeGraph in Rust. Adapters ingest Model, Structure and git. A SymbolLinker joins by SCIP key, then by file + name + range, with a confidence badge. The matrix, impact, tags, briefs and MCP tools all read the same graph.

Consequences

  • Symbol identity is the main technical risk; a real-repo golden test is required.
  • When the linker is uncertain, the UI shows confidence rather than hiding the mismatch.
  • Each adapter can evolve without changing downstream consumers.
