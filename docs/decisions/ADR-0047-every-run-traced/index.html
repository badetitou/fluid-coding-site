ADR-0047 — Every agent run is traced: Claude, opencode and Ollama

  • Status: proposed
  • Date: 2026-11-27
  • Deciders: Benoit (to validate)
  • Amends: ADR-0027 (GenAI trace model), ADR-0042 (opencode live events), ADR-0046 (transcript fallback)

Context

With session tracing on, a run still left nothing usable in session analysis:

  • Claude Code exported a full trace (interaction → model calls → tools → sub-agent work), but every span carried Claude’s own session UUID, which no chat records, so none was ever matched.
  • opencode run hands the prompt to the OpenCode desktop app’s background service when it is running. That process never saw the injected OTLP environment, so tool and step spans were not exported at all.
  • Ollama (ollama run) exports no spans.

Decision

  1. Runs are tagged with their chat. Each spawn sets OTEL_RESOURCE_ATTRIBUTES=fluid.conversation.id=<chat> (Claude and opencode both honour it), and the receiver files a span under that id before any provider conversation id.
  2. CLIs are started so they export. With tracing on, opencode run gets --standalone (a private server that inherits the environment; the live opencode serve path already did) and ollama run gets --verbose, whose token counts are parsed from stderr and reported as an AgentEvent::Usage.
  3. fluid records its own run span. When a background run settles, the server appends one invoke_agent span (fluid.source = run) with the real start and end, the provider, the usage it was told and the failure, if any.
  4. Provider adapters read the whole set. Claude: the interaction and permission-wait spans are dropped, a tool.execution with children becomes the sub-agent in place of its Agent/Task call, model calls are named LLM · <model>. opencode: a child session nests under the subagent/task call that started it, steps are named LLM · <model>.
  5. Assembly (fluid_core::session_graph::assemble_spans, pure): provider roots nest under the run that was going when they started; without provider spans, the last transcript turns take the timing and usage of the matching runs. A provider sub-agent borrows the transcript’s label.

No wire type changes.

Consequences

  • Claude and opencode runs show model calls with durations and tokens, tool calls and nested sub-agents; Ollama runs show each turn’s duration, token usage and failure.
  • Runs made before this change keep what they had; Claude traces stored without the tag stay unmatched.
